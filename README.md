# RO_GearSync — 公會裝評／聯賽戰績自動擷取工具

> RO 仙境傳說：世界之旅 — 透過雷電模擬器自動擷取公會成員的**裝備評分**與
> **公會聯賽戰績**，寫入本地 Excel。

📦 **下載連結**：<https://github.com/dave851221/ro_gear_sync/releases/latest>

每週要把 100+ 位公會成員的裝評與聯賽數據逐一抄到 Excel 太累，這支工具會自動幫你完成。
本說明書專為**公會幹部 / 成員**撰寫，分成四個區塊：

1. [環境設置](#1-環境設置)（第一次使用必看）
2. [更新裝評 SOP](#2-更新裝評-sop)（每週例行操作）
3. [進階](#3-進階)（裝評分析、OCR 重新分析、設定檔調整）
4. [聯賽戰績擷取](#4-聯賽戰績擷取)（掃描公會聯賽的個人戰績）

## 1. 環境設置

只需要做一次。完成後，之後每週只要按 [§2 SOP](#2-更新裝評-sop)。

### 1.1 你需要準備什麼

| 項目 | 說明 |
|---|---|
| **Windows 10 / 11 電腦** | 工具是 Windows 專用 |
| **雷電模擬器 9**（LDPlayer 9） | RO 手遊跑在模擬器上 |
| **RO 仙境傳說：世界之旅** | 安裝在雷電裡，能正常登入並進入公會 |
| **RO_GearSync 整包** | 由上方下載連結取得，下載後解壓即可（包含 `RO_GearSync.exe`、`_internal/`、`config.ini`、`README.md`） |

### 1.2 雷電模擬器設定（最關鍵）

#### (1) 開啟 ADB 偵錯

雷電右上角 ☰ → **設定 → 其他設定 → ADB 偵錯 → 「開啟本地連接」**。
> 沒打開這個，本工具完全連不到模擬器。

#### (2) 多開使用者請注意

如果你雷電裡開了多個實例，工具會出現下拉選單讓你選；只要選**正在跑 RO 的那一個**即可。

### 1.3 解壓並放置工具

把 `RO_GearSync_YYYYMMDD.7z` 解壓到任何位置，例如：
```
C:\Software\RO_GearSync\
```
路徑請避免中文與空格，否則某些情況下 PyInstaller 打包的 exe 啟動會有問題。

> 💡 **解壓 .7z**：Windows 11 23H2 以上已內建支援 .7z 解壓；舊版 Windows 請先安裝 [7-Zip](https://www.7-zip.org/) 或 [WinRAR](https://www.win-rar.com/)。

### 1.4 如果你已經有現成的 Excel 檔

把既有的 `guild_scores.xlsx`（或公會在用的那份 Excel）**放到 [`data/`](data/) 資料夾底下**：

```
C:\Software\RO_GearSync\
├── RO_GearSync.exe
├── config.ini
└── data\
    └── guild_scores.xlsx   ← 把舊檔丟到這裡
```

工具會直接接續使用、不會洗掉原本的資料。如果 `data/` 資料夾還不存在，先手動建立一個即可。

### 1.5 第一次啟動

雙擊 [`RO_GearSync.exe`](dist/RO_GearSync/RO_GearSync.exe)。第一次啟動會自動：

- 建立 `data/`（放 Excel 與每次擷取的暫存）
- 建立 `data/backups/`（每次寫入前自動備份原 Excel）
- 建立 `logs/`（除錯用）
- 建立 / 讀取 [`config.ini`](config.ini)（設定檔，見 [§3.3](#33-進階設定-configini)）

### 1.6 防毒軟體提示

PyInstaller 打包的執行檔常被 Windows Defender / 卡巴斯基誤判。出現警告時請點 **「仍要執行」** 或把整個資料夾加入白名單。

## 2. 更新裝評 SOP

每週固定流程，整套跑下來 **約 15~20 分鐘**（150 人公會約 13~18 分鐘掃描 + 約 2 分鐘人工複核）。

### 2.1 開始前準備

1. **打開雷電模擬器**，啟動 RO 並登入你的角色
2. **進入公會 → 公會成員列表**
3. **把成員列表滑到「最上方」**（重要！工具會由上往下掃）
4. **雷電視窗不需要保持在前景** — 工具透過 ADB 直接跟模擬器裡的 Android 系統溝通，與宿主視窗大小、位置、是否最小化完全無關。啟動掃描後你可以把雷電最小化、繼續用電腦做別的事，但**不能關掉雷電進程**、也**不能在雷電裡操作 RO**（會打斷掃描節奏）
5. **截圖階段結束後，工具會跳出提示視窗**。看到提示之後，**就可以直接把雷電與遊戲關掉**（OCR 辨識與寫入 Excel 是用本機已存下的截圖跑的，不再需要連雷電）

### 2.2 啟動工具

雙擊 [`RO_GearSync.exe`](dist/RO_GearSync/RO_GearSync.exe) 開啟主視窗。

### 2.3 環境檢查必須全部綠燈

如果有紅燈，依提示處理後按 **「🔄 重新偵測」**：

| 紅燈訊息 | 處理方式 |
|---|---|
| `找不到 adb.exe` | 確認雷電安裝路徑；可在 [`config.ini`](config.ini) 的 `ldplayer_dir` 手動指定 |
| `ADB 未連線` | 雷電的 ADB 偵錯沒打開，回 [§1.2 (1)](#1-開啟-adb-偵錯) |
| `模擬器：未偵測到實例` | 雷電還沒啟動，或實例沒開機 |

### 2.4 如有成員改名 → 先去登記

掃描開始前，**如果你知道有公會成員改名了**：

1. 按 **「✏ 改名 / 管理成員」**
2. 在搜尋框輸入成員的**舊名**
3. 點選那一列 → 輸入**新名** → 「確認改名」
4. 跳出二次確認 → 確認

> **為什麼要先登記？**
> 如果不登記，工具會把改名後的玩家當成「找不到對應」的新人，掃描結果會出現多餘的紅色新列。先登記能讓 Excel 的歷史紀錄正確接在原本那一列底下。
>
> 也可以不登記，掃描完再把紅色新列的「最高裝評」等資料手動合併到原列 — 但相對麻煩。

### 2.5 按下「🚀 開始掃描」

接下來工具會：

1. 拍下雷電目前的畫面，確認是否為公會成員列表（不是的話會跳警告）
2. 自動「**截圖 → 滑動 → 截圖 → 滑動 → ...**」直到偵測到列表已捲到底
3. **過程中請不要在雷電裡操作 RO**（不能切換頁面、不能自己滑動、不能登出）。可以最小化雷電、用電腦做其他事，只要別碰到 RO 視窗就好。

掃描過程中主視窗會即時顯示：

```
#   成員                  裝評        變化
─────────────────────────────────────────
#08  杰尼衰              48,800   (+1,500)  ← 綠色 = 比上次高
#09  衰星高照            71,702   (+500)
#10  (辨識中…)           85,493            ← 灰色 = phase B 模糊比對中
#11  押比鴨鴨            73,268   (-300)   ← 紅色 = 比上次低
#12  阿明                50,000   (±0)
#13  未配對 ｜ OCR: p    50,721            ← 紅底 = 對不到 Excel 任何人
```

截圖階段跑完之後工具會提示你「截圖完成」，**此時就可以關掉雷電與遊戲**，剩下的 OCR 與寫入 Excel 完全在本機進行。

### 2.6 掃描完成 → 結束統整對話框

掃描跑完會跳一個對話框，分成兩區：

#### ❶ Excel 有但本次沒掃到

可能是退會、OCR 漏看、或當時不在線。工具會列出這些成員與「上次紀錄」。

- 如果你知道這位成員的本次裝評 → **直接填進「本次裝評」欄**，工具會幫你寫進去
- 不填就維持空白（這欄該日期就會是空的）
- 如果該列出現「套用」勾選框，代表 OCR 找到一個**相似但不完全一致**的名字
  （形近字、OCR 誤判一兩個字）。該列下方會直接附上 OCR 結果、相似度、信心
  與**原始截圖縮圖**讓你核對 — 勾「套用」就把提案的裝評寫入這位成員，
  下次掃描同一個 OCR 拼字就會直接精確命中；不信任提案也可以自己手填

#### ❷ 辨識到但無 Excel 對應

OCR 看到了名字、但**完全找不到任何 Excel 對應**（fuzzy 分數也不夠）。對話框會顯示原始截圖縮圖讓你眼睛確認。

每筆有一個**下拉選單**，可以把這筆資料**指認為 ❶ 裡的某位成員**（常見原因：
名字被截斷或誤讀太嚴重，fuzzy 也對不到）。指認後該筆裝評會寫入該成員，
並記住這個 OCR 拼字供下次精確命中。維持預設「忽略」則**不寫入 Excel**。

同一位成員一次掃描只能有一筆裝評 — 若指認的成員已勾了「套用」、已手填、
或已被另一筆指認，工具會跳警告並在儲存前擋下，請擇一保留。

#### 按「確認並儲存」

工具會：

1. 自動備份原 Excel 到 `data/backups/guild_scores_YYYYMMDD_HHMMSS.xlsx`
2. 在 Excel 新增一個欄位 `YYYY-MM-DD`，把本次裝評寫入
3. 更新「最高裝評」欄（只有比舊值高才會更新）
4. 日期欄**最多保留 10 個**：超過時自動刪除最舊的日期欄（歷史峰值仍保留在
   「最高裝評」；被刪日期的完整資料還在步驟 1 的備份檔裡）
5. 跳出「儲存成功」對話框，可選擇直接打開 Excel

沒配對成功也沒指認的 OCR 結果**不會寫入**（不會追加紅列）——真的有新成員
入會時，請自行在 Excel 加一列並填好 `ID` 與 `遊戲ID`，下次掃描就會配對到。

### 2.7 寫入完成

所有資訊已經寫入本機的 [`data/guild_scores.xlsx`](data/guild_scores.xlsx) 檔案中，可以自行拿去參考使用。關閉視窗即可離開工具，背景連線會自動清除。

## 3. 進階

### 3.1 裝評分析 — 看懂你的 Excel

[`data/guild_scores.xlsx`](data/guild_scores.xlsx) 是**寬表格**：每位成員一列，每次掃描新增一個日期欄。

| 欄位 | 用途 |
|---|---|
| `ID` (A 欄) | 你手動維護的成員編號，工具完全不會動 |
| `遊戲ID` | 你親手填的「正確暱稱」（真值）。配對優先採信此欄 |
| `職業` | 自由文字欄，給你自己分類用（例如紳商、機械師等） |
| `Last_OCR_ID` | OCR 看過的暱稱拼字（用於下一次配對）。可存多個歷史變體，以「｜」分隔、最新在前、最多 8 個——同一人不同次掃描的誤讀都會留下來，之後再出現同樣誤讀就能直接配對，不用再人工確認 |
| `OCR信心` | OCR 信心（0–1） |
| `最高裝評` | 該成員歷史最高裝評。**可手動覆寫**：填比現有日期欄都高的歷史峰值，工具不會蓋掉，只會在新捕捉值更高時往上更新 |
| `2026-05-19`、`2026-05-26` ... | 每天一欄，內容是該天看到的最高裝評。**最多保留 10 欄**：新日期進來超過上限時，最舊的日期欄會自動刪除（歷史最大值不會丟——「最高裝評」永遠留著；舊資料也都在 `data/backups/` 的備份裡） |

> ⚠️ **請不要在這份 Excel 自行新增欄位或工作表**：工具每次寫入時會整本重建，
> 只保留上表列出的欄位與日期欄，自行加的欄位、分頁與儲存格格式都會遺失。
> 想做自己的分析，請複製一份出去再加工。

### 3.2 OCR 重新分析（不用重新掃描）

每次掃描的原始截圖都存在 [`data/captures/YYYYMMDD_HHMMSS/`](data/captures/) 裡。主視窗最上方選單 **「重新分析截圖」** 提供兩種重跑模式：

#### (1) 重新讀取 members.json

選一個既有 session 的 `members.json` → 直接走配對 + 結束統整流程（**秒級**，不跑 OCR）。

**典型用途**：你補填了某位成員的 `遊戲ID`，想把上週掃描結果重新配對到他、不必再開雷電掃。

#### (2) 重新分析截圖歷史 page

對 session 的截圖**重跑一次完整 OCR**。一般用不到 — 只有在你**調整了 OCR 參數**（例如把 `primary_model` 改成 `v5-server`）之後想驗證新設定才會用。

### 3.3 進階設定 [`config.ini`](config.ini)

放在 `RO_GearSync.exe` 旁邊，文字編輯器即可修改。修改後重啟工具，或在 GUI 按「重新偵測」生效。

```ini
[paths]
ldplayer_dir   =          # 留空 = 自動搜尋；指定 ex. C:\Software\LDPlayer\LDPlayer9
workbook_path  =          # 留空 = data/guild_scores.xlsx；可指定到任意絕對路徑
data_dir       =          # 留空 = ./data
logs_dir       =          # 留空 = ./logs

[ocr]
primary_model      =      # 留空 = v5-mobile（快）；可改 v5-server（慢但更準）
fallback_model     =      # 留空 = v5-server；改 off 可關閉
fallback_threshold =      # 留空 = 0.90；信心低於此值的列會走 fallback

[google_sheet]            # 雲端名冊同步（見 §5）
sheet_url           =     # 公會名冊 Google 試算表完整網址（機密）
oauth_client_id     =     # 發佈包已內建，一般不用動
oauth_client_secret =
```

**常見調整**：

| 你想做什麼 | 改哪一個 |
|---|---|
| Excel 想放在別的位置 | `workbook_path = D:\RO\guild_scores.xlsx` |
| 雷電裝在非標準路徑 | `ldplayer_dir = D:\LDPlayer9` |
| 追求最高辨識率（不在意慢） | `primary_model = v5-server` |
| 用 mobile 但更積極做 fallback | `fallback_threshold = 0.95` |

### 3.4 備份與還原

每次寫入 Excel 前都會自動備份到 [`data/backups/`](data/backups/)，檔名含時間戳：
```
guild_scores_20260526_204215.xlsx
```
要還原：直接把備份檔複製出來、覆蓋目前的 `guild_scores.xlsx` 即可。

### 3.5 疑難排解

| 症狀 | 處理 |
|---|---|
| 雙擊 .exe 沒反應 | 解壓位置不要有中文 / 空格；防毒軟體加白名單 |
| 「找不到 adb.exe」 | 雷電還沒裝完整版，或安裝在非預設路徑（用 `config.ini` 指定） |
| 環境檢查永遠紅燈 | 雷電 ADB 偵錯沒開，回 [§1.2 (1)](#1-開啟-adb-偵錯) |
| 大量「未配對」紅列 | 公會列表 UI 改版（遊戲改版後可能要更新模板）→ 找代杰求救 |
| Excel 寫不進去 | Excel 還開著沒關，關掉再試 |
| 連續紅底「OCR 看到名字但對不到」 | 找代杰求救 |

## 4. 聯賽戰績擷取

自動掃描「公會聯賽 → 歷史戰績」畫面，記錄每位成員有沒有參戰（主戰場／副戰場）
與所有個人數據，輸出成獨立的 Excel 快照檔。與裝評功能**完全分開**，不會動到
裝評的 `guild_scores.xlsx`。

### 4.1 第一次使用前的準備

1. **Gemini API 金鑰**：聯賽畫面用 Google Gemini 辨識（藝術字與表格比本地 OCR 穩）。
   到 <https://aistudio.google.com/apikey> 免費申請一把，填進 `config.ini`：
   ```ini
   [gemini]
   api_key = 你的金鑰
   ```
   模型預設 `gemini-3.1-flash-lite`（免費額度即可）；想換型號填 `model =`。
2. **聯賽名冊 `data/league_scores.xlsx`**：欄位為
   `ID｜遊戲ID｜職業｜Last_OCR_ID`。你只要維護前三欄（遊戲ID 空白的列
   會被當成空位自動略過；ID 請勿重複或留空）；`Last_OCR_ID` 由工具在
   每次掃描後自動回寫，讓下次辨識越來越準。

### 4.2 掃描 SOP

1. 在遊戲進入 **公會聯賽 → 歷史戰績**，切到想掃的頁面。
2. 開 RO_GearSync，切到「**聯賽評分**」分頁。共有五個畫面可掃：
   主戰場（輸出／輔助）＋ 副戰場（輸出／輔助／戰略）。
3. 遊戲停在哪個畫面，就按那個畫面的綠色「📸 拍攝」按鈕（主戰場亮綠、副戰場深綠）。
   拍攝約 30–60 秒，會自動滑動左側我方列表、拍到底自動停。
4. 聽到提示音＋「✅ 拍攝完成 — 可切換下一個畫面」後，就能去遊戲切下一頁接著拍；
   **分析在背景進行**，卡片上會顯示進度（「分析中 5/13 頁（已辨識 42 人）」）。
   若出現「⚠ Gemini 伺服器忙碌，N 秒後重試」是官方尖峰，等它自動重試即可。
5. 五個畫面不必全拍——想拍幾個就拍幾個。全部分析完成後按「🧮 產出結果」。
6. 確認對話框會依畫面列出對帳摘要（參戰人數 vs 辨識人數），以及對不到名冊的名字
   （可下拉指定成員或保留紅列；指定過一次後，下次同樣的辨識結果就會自動對上）。
   按「確認寫入 Excel」輸出：
   ```
   league_scores_20260703_213045.xlsx   ← 以當下時間命名，每按一次產生一份新檔
   ```
   視窗不會關閉——調整選項後可再按一次，再產生一份新檔。

### 4.3 看懂聯賽 Excel

單一工作表「聯賽戰績」，一人一列：

| 欄位 | 說明 |
|---|---|
| 參與 | `主`／`副`／`主+副`，空白＝這場沒參加（綠/藍/深綠底色） |
| 主-擊殺 … 主-復活 | 主戰場的輸出＋輔助共 8 欄 |
| 副-擊殺 … 副-王的傷害 | 副戰場的輸出＋輔助＋戰略共 12 欄 |
| 紅底列 | 需要人工確認的資料（對不到名冊、你選擇保留紅列的名字） |

### 4.4 補充

* **分析失敗**（例如 Gemini 過載超過重試上限）：截圖都還在，再按一次該畫面的
  拍攝按鈕，選「重新分析」即可，不用重拍。
* **重新分析舊紀錄**：上方選單 工具 → 重新分析聯賽截圖，可挑選過去任何一次的
  截圖紀錄重跑辨識，不需要開遊戲。
* 拍攝期間請不要操作模擬器；也不要在遊戲裡掛機打怪（撿寶通知會蓋住表格）。

## 5. 雲端名冊同步

把公會在 **Google 試算表**上維護的成員名冊（編號／遊戲ID／職業）同步到本機的
`guild_scores.xlsx` 與 `league_scores.xlsx`，不用再手動維護兩份 Excel 的成員異動。

### 5.1 第一次使用前的準備

1. 打開 `config.ini`，在 `[google_sheet]` 的 `sheet_url =` 貼上名冊試算表的
   **完整網址**（瀏覽器網址列整串複製）。此網址是機密，請勿外流。
2. 上方選單 **工具 → 從雲端名冊同步…**，第一次會自動打開瀏覽器：
   * 選擇**看得到該試算表**的 Google 帳號；
   * 若出現「Google 尚未驗證這個應用程式」，點 **進階 → 前往（不安全）** 繼續
     （這是自製小工具的正常提示）；
   * 按「**允許**」後回到工具即可。之後就不會再跳瀏覽器。

> 讀取試算表用的是**你授權的那個帳號**的權限——帳號看不到表單，同步就會回報
> 無權限。要換帳號：工具 → 清除 Google 授權，再同步一次。

### 5.2 同步流程

1. 工具會抓試算表上編號 1–150 的成員列（順序打亂沒關係；下方排隊名單不會被讀到）。
2. 比對兩份 Excel 後跳出**變更確認**視窗，每筆變更都要人工確認才會寫入：
   * **退會**（勾選後套用）：該 ID 的 遊戲ID／職業／Last_OCR_ID **與裝評紀錄**清空，ID 保留；
   * **新進**（勾選後套用）：遊戲ID／職業 填入原本的空位；
   * **遊戲ID 不同**：工具無法自行判斷，由你三選一——
     **換人**（有人退了、新人補進這個編號：舊資料含裝評紀錄全部清空後填入新人）／
     **同一人改名/換職業**（裝評紀錄保留，遊戲ID 與職業更新為表單上的值）／**略過**。
   * **最高裝評更新**：試算表若有「裝備評分」欄，工具會逐一比對
     `guild_scores.xlsx` 的「最高裝評」——表單數字**比較大**才更新（只升不降），
     整批共用一個勾選框。新進／換人會直接以表單數字填入最高裝評；
     改名則同樣只升不降。
   * 反過來**本地最高裝評比表單大**（或表單該格空白）的成員，工具**不會**去改
     試算表，只會在視窗底部以紅字提醒有幾筆——請記得把掃描完的裝備評分
     手動更新回雲端名冊。
3. 按「套用已確認項目」寫入。寫入前兩份 Excel 都會自動備份到 `data/backups/`。

### 5.3 注意事項

* 試算表上**編號重複**、或 Excel 裡 **ID 重複**：該編號整筆不同步並顯示警告，請先修正。
* 試算表有成員但 Excel 沒有那個 ID 的列：不會自動加列，請先在 Excel 補上該 ID。
* 同步前請先關閉 Excel（檔案被開著會寫入失敗）。
